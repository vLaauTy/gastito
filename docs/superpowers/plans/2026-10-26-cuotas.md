# Compras en cuotas (Etapa 6, parte D) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Dejar que un mensaje como "zapatillas 84000 en 6 cuotas con la tarjeta" (o "6 cuotas de 14000") guarde un plan de cuotas; cada mes cuenta como gasto solo la cuota de ese mes, ya confirmada, con "(cuota 3 de 6)" en la descripción; el usuario puede cancelar el plan (se borran las cuotas futuras, no las pasadas) con `/cuotas`.

**Architecture:** El modelo de datos ya existe (migración V7: tabla `plan_cuotas`, y `movimiento.cuota_actual`/`cuota_total`/`plan_cuotas_id` ya están en V1/V7) — no hace falta migración nueva. Se agrega un paquete `ar.gastito.cuota` (entidad `PlanCuotas`, repositorio y servicio) paralelo a `ar.gastito.fijo` y `ar.gastito.juntada`. La IA extrae `cuotasCantidad`/`cuotasValorCuota` en la misma llamada que interpreta el gasto (igual que hace hoy con las juntadas); Java calcula el total y el valor de cada cuota, nunca la IA. El gasto pendiente (cuota 1) sigue el flujo normal de tarjeta (Guardar/Editar/Cancelar); al guardarlo se generan, ya confirmadas, las cuotas 2..N con fecha en los meses siguientes (mismo día del mes que la compra). Cancelar el plan borra los movimientos de cuotas con fecha futura.

**Tech Stack:** Java 25, Spring Boot 3, Spring Data JPA, JUnit 5, AssertJ, `@DataJpaTest` con H2 (perfil `test`).

**Spec:** `docs/pedidos/etapa-6.md`, sección "Parte D: compras en cuotas".

## Review Focus

- **Un plan con "en 1 cuota" o sin cantidad válida no es un plan**: el gasto queda como un gasto común (igual que una juntada con menos de 2 personas). Cubierto en la Tarea 3 (`PedidoCuotasTest`/`ValidadorInterpretacionTest`).
- **Si solo se dice el valor de cada cuota ("6 cuotas de 14000"), sin el total**: Java calcula el total (valor × cantidad); la IA no debe inventar el total. Cubierto en la Tarea 3.
- **El total no siempre es divisible exacto entre la cantidad de cuotas**: el valor de cada cuota se redondea a 2 decimales (HALF_UP) y el total que se guarda es el dicho por el usuario, no la suma exacta de las cuotas. Cubierto en la Tarea 2 (`PlanCuotasTest`).
- **Categoría, tarjeta y monto pueden cambiar en la tarjeta de confirmación** (el usuario edita antes de guardar, o elige categoría con botones) **después de crear el plan**: al guardar la primera cuota, el plan tiene que resincronizar valor de cuota, total, categoría y tarjeta desde el movimiento ya confirmado, no desde lo que había al interpretar el mensaje. Cubierto en la Tarea 2 (`PlanCuotasServiceTest`).
- **Cancelar un plan que ya terminó** (no quedan cuotas futuras) tiene que funcionar igual (no rompe, no borra nada) y marcarlo `CANCELADO`. Cubierto en la Tarea 2.

```java
@Table(name = "plan_cuotas")
public class PlanCuotas {
    // id, descripcion, total, cantidad, valorCuota, fechaCompra (LocalDateTime), primerMes (LocalDate, día 1),
    // categoria (ManyToOne, nullable), tarjeta (ManyToOne, nullable), estado (ACTIVO por defecto), creadoEn.

    protected PlanCuotas() {}

    public PlanCuotas(String descripcion, BigDecimal total, int cantidad, BigDecimal valorCuota,
            LocalDateTime fechaCompra, YearMonth primerMes, Categoria categoria, TarjetaCredito tarjeta,
            LocalDateTime ahora) {
        if (cantidad < 2) throw new IllegalArgumentException("Un plan de cuotas tiene que ser de al menos 2 cuotas");
        if (total == null || total.signum() <= 0 || valorCuota == null || valorCuota.signum() <= 0) {
            throw new IllegalArgumentException("El total y el valor de la cuota tienen que ser mayores a cero");
        }
        // asignar campos; estado = EstadoPlanCuotas.ACTIVO
    }

    /** El día de la cuota N: el mismo día del mes que la compra, o el último si el mes no lo tiene. */
    public LocalDateTime fechaDeCuota(int numero) {
        YearMonth mes = YearMonth.from(primerMes).plusMonths(numero - 1);
        int dia = Math.min(fechaCompra.getDayOfMonth(), mes.lengthOfMonth());
        return mes.atDay(dia).atTime(fechaCompra.toLocalTime());
    }

    /** Al guardar la primera cuota (ya confirmada): el plan toma lo que quedó, no lo que había al interpretar. */
    void actualizarValores(BigDecimal valorCuotaConfirmado, Categoria categoriaConfirmada, TarjetaCredito tarjetaConfirmada) {
        this.valorCuota = valorCuotaConfirmado;
        this.total = valorCuotaConfirmado.multiply(BigDecimal.valueOf(cantidad));
        this.categoria = categoriaConfirmada;
        this.tarjeta = tarjetaConfirmada;
    }

    public void cancelar() {
        if (estado != EstadoPlanCuotas.ACTIVO) {
            throw new IllegalStateException("El plan " + id + " ya está " + estado);
        }
        estado = EstadoPlanCuotas.CANCELADO;
    }

    // getters de todos los campos
}
```

```java
@Service
public class PlanCuotasService {

    static final java.time.LocalTime HORA_DE_LA_CUOTA = java.time.LocalTime.of(9, 0);

    private final PlanCuotasRepository planes;
    private final MovimientoRepository movimientos;
    private final MovimientoService movimientoService;
    private final CuotaProperties properties;
    private final Clock clock;

    // constructor con inyección de los 5

    @Transactional
    public Movimiento crear(Long movimientoId, int cantidad, BigDecimal total) {
        Movimiento m = movimiento(movimientoId);
        if (m.getMonto() == null) {
            throw new IllegalStateException("Falta el monto para armar el plan de cuotas");
        }
        YearMonth primerMes = YearMonth.from(m.getFechaHora());
        if (properties.primeraCuota() == CuotaProperties.PrimeraCuota.MES_SIGUIENTE) {
            primerMes = primerMes.plusMonths(1);
        }
        BigDecimal valorCuota = total.divide(BigDecimal.valueOf(cantidad), 2, RoundingMode.HALF_UP);
        PlanCuotas plan = planes.save(new PlanCuotas(m.getDescripcion(), total, cantidad, valorCuota,
                m.getFechaHora(), primerMes, m.getCategoria(), m.getTarjeta(), LocalDateTime.now(clock)));
        m.prepararCuota(plan.getId(), 1, cantidad);
        return m;
    }

    @Transactional
    public List<Movimiento> alGuardar(Long movimientoId) {
        Movimiento primera = movimiento(movimientoId);
        PlanCuotas plan = plan(primera.getPlanCuotasId());
        plan.actualizarValores(primera.getMonto(), primera.getCategoria(), primera.getTarjeta());
        List<Movimiento> nuevas = new ArrayList<>();
        for (int numero = 2; numero <= plan.getCantidad(); numero++) {
            Movimiento cuota = movimientoService.crearPendiente(MovimientoInterpretado.conCategoria(
                    plan.getValorCuota(), plan.getDescripcion(), plan.getCategoria(), null, null, plan.getTarjeta(),
                    plan.fechaDeCuota(numero)), Origen.AUTOMATICO, null);
            cuota.prepararCuota(plan.getId(), numero, plan.getCantidad());
            cuota.confirmar();
            nuevas.add(cuota);
        }
        return nuevas;
    }

    @Transactional
    public VistaPlanCuotas cancelar(Long planId) {
        PlanCuotas plan = plan(planId);
        plan.cancelar();
        movimientos.borrarCuotasFuturas(planId, LocalDate.now(clock).plusDays(1).atStartOfDay());
        return vista(plan);
    }

    @Transactional(readOnly = true)
    public List<VistaPlanCuotas> activos() {
        return planes.findByEstadoOrderByIdDesc(EstadoPlanCuotas.ACTIVO).stream()
                .filter(p -> !movimientos.findByPlanCuotasIdOrderByCuotaActual(p.getId()).isEmpty())
                .map(this::vista).toList();
    }

    @Transactional(readOnly = true)
    public VistaPlanCuotas vista(Long planId) {
        return vista(plan(planId));
    }

    private VistaPlanCuotas vista(PlanCuotas plan) {
        LocalDate hoy = LocalDate.now(clock);
        List<Movimiento> cuotas = movimientos.findByPlanCuotasIdOrderByCuotaActual(plan.getId());
        int pagadas = (int) cuotas.stream().filter(c -> !c.getFechaHora().toLocalDate().isAfter(hoy)).count();
        Optional<Movimiento> proxima = cuotas.stream().filter(c -> c.getFechaHora().toLocalDate().isAfter(hoy)).findFirst();
        String tarjeta = plan.getTarjeta() == null ? null : plan.getTarjeta().getNombre();
        return new VistaPlanCuotas(plan.getId(), plan.getDescripcion(), plan.getTotal(), plan.getCantidad(),
                plan.getValorCuota(), plan.getCategoria() == null ? null : plan.getCategoria().getNombre(),
                plan.getCategoria() == null ? null : plan.getCategoria().getEmoji(), tarjeta, pagadas,
                plan.getCantidad() - pagadas, proxima.map(c -> c.getFechaHora().toLocalDate()).orElse(null),
                plan.getEstado() == EstadoPlanCuotas.ACTIVO);
    }

    private PlanCuotas plan(Long id) {
        return planes.findById(id).orElseThrow(() -> new NoSuchElementException("No existe el plan " + id));
    }

    private Movimiento movimiento(Long id) {
        return movimientos.findById(id).orElseThrow(() -> new NoSuchElementException("No existe el movimiento " + id));
    }
}
```

```java
package ar.gastito.interpretacion;

import java.math.BigDecimal;
import java.math.RoundingMode;

/**
 * "zapatillas 84000 en 6 cuotas" (o "6 cuotas de 14000"): cuántas cuotas y cuánto, ya resuelto por Java (la IA no
 * calcula). Null si no es un plan creíble.
 */
public record PedidoCuotas(int cantidad, BigDecimal total, BigDecimal valorCuota) {

    static final int MAXIMO_CUOTAS = 24;

    static PedidoCuotas de(String cantidadIa, String valorCuotaIa, BigDecimal montoTotal) {
        if (cantidadIa == null || !cantidadIa.strip().matches("\\d{1,2}")) {
            return null;
        }
        int cantidad = Integer.parseInt(cantidadIa.strip());
        if (cantidad < 2 || cantidad > MAXIMO_CUOTAS) {
            return null;
        }
        BigDecimal valorDicho = ValidadorInterpretacion.monto(valorCuotaIa).orElse(null);
        BigDecimal total = montoTotal != null ? montoTotal
                : valorDicho != null ? valorDicho.multiply(BigDecimal.valueOf(cantidad)) : null;
        if (total == null) {
            return null;
        }
        total = total.setScale(2, RoundingMode.HALF_UP);
        BigDecimal valorCuota = total.divide(BigDecimal.valueOf(cantidad), 2, RoundingMode.HALF_UP);
        return new PedidoCuotas(cantidad, total, valorCuota);
    }
}
```

```java
@Component
public class ConversacionCuotas {

    static final String CANCELAR_PLAN = "cup";

    private final PlanCuotasService planes;
    private final MovimientoService movimientos;
    private final Tarjetas tarjetas;
    private final FormatoMensajes formato;

    // constructor

    public Movimiento crear(Movimiento m, PedidoCuotas pedido) {
        planes.crear(m.getId(), pedido.cantidad(), pedido.total());
        return movimientos.buscar(m.getId());
    }

    public List<Accion> guardada(int mensajeId, MovimientoService.Confirmacion c) {
        List<Movimiento> siguientes = planes.alGuardar(c.movimiento().getId());
        String html = tarjetas.guardado(c.movimiento(), c.totalMesCategoria())
                + (siguientes.isEmpty() ? "" : "\n🗂 Plan de " + c.movimiento().getCuotaTotal() + " cuotas. Próxima: "
                        + formato.fecha(siguientes.get(0).getFechaHora()));
        return List.of(new Accion.Editar(mensajeId, html, Teclado.NINGUNO), new Accion.Avisar("✅ Guardado"));
    }

    public boolean esBoton(String accion) {
        return CANCELAR_PLAN.equals(accion);
    }

    public List<Accion> boton(int mensajeId, String accion, long id) {
        VistaPlanCuotas p = planes.cancelar(id);
        return List.of(new Accion.Editar(mensajeId, textoDeLista(planes.activos()), tecladoDeLista(planes.activos())),
                new Accion.Avisar("🗑 Plan de " + html(p.descripcion()) + " cancelado"));
    }

    public List<Accion> lista() {
        List<VistaPlanCuotas> activos = planes.activos();
        return List.of(Accion.Enviar.conBotones(textoDeLista(activos), tecladoDeLista(activos)));
    }

    private String textoDeLista(List<VistaPlanCuotas> activos) {
        if (activos.isEmpty()) {
            return "🗂 No tenés compras en cuotas.";
        }
        StringBuilder sb = new StringBuilder("🗂 <b>Tus compras en cuotas</b>");
        for (VistaPlanCuotas p : activos) {
            sb.append("\n• ").append(p.emoji() == null ? "" : p.emoji() + " ").append(html(p.descripcion()))
                    .append(": cuota ").append(p.cuotasPagadas()).append(" de ").append(p.cantidad())
                    .append(" (").append(formato.pesos(p.valorCuota())).append(" c/u, total ")
                    .append(formato.pesos(p.total())).append(')')
                    .append(p.proximaCuota() == null ? " · terminó"
                            : " · próxima " + formato.fecha(p.proximaCuota().atStartOfDay()));
        }
        return sb.toString();
    }

    private static Teclado tecladoDeLista(List<VistaPlanCuotas> activos) {
        Teclado.Constructor t = Teclado.constructor();
        activos.forEach(p -> t.fila(new Teclado.Boton("🗑 Cancelar " + p.descripcion(), CANCELAR_PLAN + ":" + p.id())));
        return t.build();
    }
}
```
